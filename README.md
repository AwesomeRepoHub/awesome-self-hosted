# 自部署应用精选

收录适合个人和小团队自行部署、掌握数据的开源应用。

## 分类

- 家庭服务
- 协作应用
- 文件服务
- 运维工具

## 精选项目

待逐项筛选后补充。每个条目包含：项目名与原始 GitHub 链接、用途、适合人群、推荐理由、主要限制、许可证和核验日期。

## 收录标准

- 用途明确，有可理解的文档或示例。
- 核验维护状态与许可证，标注归档或长期未更新情况。
- 以实际使用价值为主，Stars 仅作辅助参考。
- 引用原作者仓库，避免重复收录同一项目的镜像。
